## 📝Overview: FitLog

FitLog is a responsive fitness app built for tracking personal exercise schedules.
This multi-page app is primarily built with Next.js and TypeScript. Currently, the app is deployed
at VERCEL for [Live Preview](https://mern-a06-fit-log.vercel.app/).

## 🚀Key Features

1. Real-time dynamic metrics of various health activities displayed in a Responsive Grid System that works across mobile, tablet, desktops, etc.
2. Appropriate indicators in Navigation Bar to stay informed across the routes
3. Instant sorting of physical activities based on burned calories, duration, and ratings
4. Detailed view of every activity in a separate route
5. Engaging notifications and fallback messages to keep users engaged
